Four Core Design Challenges Solved

Team Solutions Matrix
HMW 1 Contributor: Shriram

"How might we detect slow, gradual changes in behavior before they become serious?"

Feature: Long-Term Baseline Drift & Cumulative Velocity Tracker
Exponentially Weighted Moving Average (EWMA) tracks rolling multi-day volume shifts. Captures low-and-slow data exfiltration that stays beneath per-event thresholds but exhibits continuous deviation (>15% weekly drift).

Feature: Plain-English Anomaly Narrative & 3-Second Visual Chips
Replaces cryptic JSON payloads with natural sentences (e.g., "Sophia Chen executed Cloud Bulk Sync from atypical IP (Munich) during non-business hours downloading 4.5x daily volume.") paired with instant color chips.

HMW 3 Contributor: Alfred

"How might we integrate AI-driven detection without losing human oversight?"

Feature: "Explain Why" Breakdown & Dynamic Feedback Loop
Every alert reveals exact factor contributions (Peer Deviation 40%, Off-Hours 35%, EWMA Drift 25%). Analysts take 1-click containment (Verify Threat / Step-Up MFA) or flag false positives, which automatically down-weights the signal in memory.

HMW 4 Contributor: Arshinth

"How might we make new security tools easier to onboard into an existing stack?"

Feature: Universal Telemetry Ingestion Adapter (/api/v1/telemetry/universal)
Schema-flexible ingestion route accepting CEF, Syslog, or arbitrary JSON keys. Maps forwarder aliases (`client_ip`, `src_ip`, `suser`) into normalized models in sub-second pipelines.

System Architecture Highlights

1. Streaming Pipeline

Native FastAPI WebSockets (/ws/telemetry) push sub-second events, score changes, and posture statistics to connected dashboards without HTTP polling.

2. EWMA & Closed-Loop ML

Exponentially Weighted Moving Average baseline drift detection combined with feedback-driven signal down-weighting (RULE_ODD_HOURS: 0.65x) to eliminate alert fatigue.

3. Human-in-the-Loop

No autonomous destructive lockout. Analysts inspect model contribution weights and authorize Step-Up MFA or containment actions with 1 click.
